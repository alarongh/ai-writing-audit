# Аудит заимствований, цитат и отчётов

Три команды ниже работают как промпты. В Codex из этого репозитория их можно вызвать через скилл `$source-audit`, указав имя команды и приложив материалы. [Скилл source-audit](../.agents/skills/source-audit/SKILL.md)

| Команда | Вход | Результат |
| --- | --- | --- |
| [Find Plagiarism](#find-plagiarism) | Текст, возможные источники, границы разрешённого поиска | Совпадающие фрагменты с источниками и оценкой атрибуции |
| [Check Citations](#check-citations) | Текст со ссылками, библиография, требования к оформлению | Реквизиты, соответствие ссылок списку литературы и опора каждого утверждения |
| [Analyze Similarity Report](#analyze-similarity-report) | Полный отчёт, версия работы, требования организации | Разбор выделенных блоков и порядок исправлений |

## Как работают существующие инструменты

| Инструмент | Что проверяет | Где нужна дополнительная проверка |
| --- | --- | --- |
| `check-plagiarism` из researcher-skills | Сопоставляет отрывки с предоставленными источниками, ищет близкий пересказ и пропуски ссылок | Для покрытия закрытых баз нужен отдельный отчёт. Смена тона служит поводом проверить фрагмент. [Исходный скилл](https://github.com/vadym-khodak/researcher-skills/blob/main/skills/check-plagiarism/SKILL.md) |
| Turnitin Similarity Report | Ищет совпадающий текст по доступному корпусу и показывает отмеченные фрагменты. В совпадения могут попасть оформленные цитаты. | Для каждого существенного блока смотрят оформление, контекст и источник. [Руководство Turnitin](https://guides.turnitin.com/hc/en-us/articles/23435833938701-Understanding-the-similarity-score) |
| Turnitin Draft Coach Citations Check | Ищет пары внутритекстовых ссылок и записей в библиографии в поддерживаемых стилях APA и MLA | Соответствие ссылки списку литературы и поддержка тезиса проверяются отдельно. [Руководство Draft Coach](https://guides.turnitin.com/hc/en-us/articles/21993429763469-Understanding-your-Draft-Coach-reports) |
| `citation-management` и Crossref | Ищут публикации и сверяют библиографические метаданные. Crossref позволяет найти запись по DOI или по тексту ссылки. | Даже при верных реквизитах нужно открыть источник и найти опору для конкретного тезиса. [Исходный скилл](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/citation-management/SKILL.md), [Crossref](https://www.crossref.org/documentation/retrieve-metadata/) |
| Полный отчёт «Антиплагиата» | Показывает отмеченные блоки, источники и категории совпадений, цитирования и самоцитирования | Категория может требовать пересмотра после чтения первоисточника. Зафиксируйте модули поиска и настройки отчёта, если они доступны. [Руководство «Антиплагиата»](https://docs.antiplagiat.ru/ru/pdf/private_user_guide.pdf) |

## Find Plagiarism

```text
Найди потенциальные неоформленные заимствования в приложенном тексте. Сначала сравни его с приложенными материалами. Если разрешён поиск, ищи характерные фразы и проверяй найденные страницы. Для каждого существенного совпадения укажи место в работе, подтверждённый источник и конкретное сходство. Отметь, есть ли ссылка и оформлена ли прямая цитата. Отдельно укажи близкий пересказ, повтор собственного текста, типовые выражения и случаи, где нужен полный источник.

Предложи исправления по существу: оформить цитату, указать источник, обозначить повтор собственного материала или заново объяснить идею по источнику. Укажи охват проверки и границы доступа. Не выдумывай процент совпадений. В новом тексте не используй длинное тире U+2014.
```

## Check Citations

```text
Проверь внутритекстовые ссылки и список литературы. Найди ссылки без библиографической записи, записи без ссылки, если она нужна по формату, дубли и неоднозначные пары. Затем проверь автора, название, год, издателя и DOI или URL по первичной записи. Если совпадение по названию неоднозначно, отметь кандидатов без подстановки.

Открой доступный источник и проверь, подтверждает ли он каждое утверждение, которому служит ссылкой. Для прямой цитаты сверь слова и место в источнике. Укажи статус по каждой записи: реквизиты и тезис подтверждены, подтверждена только часть тезиса, источник не подтверждает тезис, источник доступен только по метаданным или сведений недостаточно. Приведи страницу, раздел или точную ссылку для проверки. В новом тексте не используй длинное тире U+2014.
```

Для отдельной записи с известным DOI можно получить метаданные из Crossref. Команда ниже запрашивает запись статьи FActScore. Проверка содержания статьи выполняется отдельно. [Документация REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/), [FActScore](sources.md#f03)

```powershell
Invoke-RestMethod 'https://api.crossref.org/works/10.18653/v1/2023.emnlp-main.741' |
    Select-Object -ExpandProperty message |
    Select-Object DOI, title, author, published
```

## Analyze Similarity Report

```text
Разбери приложенный полный отчёт о совпадениях. Запиши систему, дату, версию проверенного файла и известные фильтры или модули. Сохрани обозначения и значения показателей из отчёта. Если отчёт содержит отдельный показатель ИИ, запиши его отдельно с названием и определением из отчёта.

Сгруппируй отмеченные фрагменты по подтверждённым источникам и проверь блоки, а не только сводную таблицу. Для каждого существенного блока укажи место, источник, наличие цитаты и ссылки, объяснение и правку. Различай корректно оформленную цитату, типовую формулировку, повтор собственной работы, совпадение без атрибуции и случай, когда данных мало. Пересекающиеся совпадения не складывай. Если видишь только сводный процент, сообщи, что нужен полный отчёт с отмеченными фрагментами. В новом тексте не используй длинное тире U+2014.
```

## Как различаются результаты

В условном отчёте блок на странице 2 отмечен как совпадение с источником А, а его часть также указана у источника Б. В документе блок оформлен как цитата из А. `Find Plagiarism` фиксирует найденное совпадение и наличие атрибуции. `Check Citations` сверяет текст цитаты, страницу источника А и запись о нём в библиографии. `Analyze Similarity Report` описывает один перекрывающийся блок и отдельно отмечает дубликат источника, если это подтверждается сравнением.

При повторной проверке сравнивайте версии одного файла и зафиксированные настройки. Например, фильтр библиографии или исключение корректных цитат может изменить показатель отчёта без изменения текста. [Руководство Turnitin](https://guides.turnitin.com/hc/en-us/articles/23435833938701-Understanding-the-similarity-score), [Руководство «Антиплагиата»](https://docs.antiplagiat.ru/ru/pdf/private_user_guide.pdf)
