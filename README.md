# Следы генерации

Библиотека для проверки русскоязычных документов, подготовленных с помощью ИИ. В ней собраны примеры ошибок, разборы исследований и правила, которые можно перенести в другой проект. Основные сценарии — отчёты о выполненной работе, служебные записки, технические документы и обзоры источников.

В Codex скилл можно вызвать явно. Например, напишите `$document-manifest Проверь отчёт по приложенным материалам и исправь подтверждённые ошибки`. В этом репозитории `AGENTS.md` также направляет Codex к скиллу при работе с документами.

Для другого репозитория скопируйте папку `.agents/skills/document-manifest/` в тот же путь от его корня. Чтобы применять манифест при каждой работе с документами, добавьте в `AGENTS.md` того проекта указание прочитать скилл перед началом работы.

## Как читать каталог

**Проверяемый дефект** можно установить по заданию, источнику или самому файлу. Например, отчёт сообщает о публикации, а журнал работы подтверждает лишь локальную сборку. Такой дефект исправляют независимо от происхождения текста.

**Редакторский сигнал** указывает на место, которое стоит перечитать. Например, «по мнению экспертов» требует проверки, если от этого мнения зависит вывод. Тире, список или повтор термина могут быть оправданы жанром. [Русская Википедия](docs/sources.md#w01), [CoAT](docs/sources.md#r01)

**Результат детектора** относится к конкретному инструменту и его условиям оценки. На новых моделях и жанрах показатели могут меняться. Для выводов об авторстве нужны данные о происхождении документа и процессе работы. [M4](docs/sources.md#d01), [RAID](docs/sources.md#d02), [Эксперимент с русскими текстами](docs/sources.md#r03)

## Как пополнять библиотеку

Для нового источника укажите оригинал, язык, материал, метод, результат и ограничение. Отделяйте вывод авторов статьи от правила, которое предлагаете для своих проектов. В карточке признака дайте наблюдаемый симптом, способ проверки, правку и случай, когда такая правка не нужна. Свяжите карточку с источником либо прямо пометьте её как проектное правило. Для примеров используйте учебные сценарии или материалы, которые разрешено включить в репозиторий.
