# Аудит текстовых артефактов

1. Запусти `python <путь-к-скиллу>/scripts/text_artifacts.py scan <файл>`. В JSON будут SHA-256 исходного файла, кодовые точки, позиции и признаки того, что можно удалить через скрипт после проверки.
2. Оцени контекст отмеченных позиций. Неразрывный пробел может удерживать число рядом с единицей, а ZWJ соединяет элементы эмодзи. Наличие Unicode-символа устанавливает только факт его присутствия. Вывод о происхождении текста требует других данных.
3. Если задача включает очистку, укажи в `clean` SHA-256 из отчёта и повтори `--remove ID` для каждого подтверждённого артефакта. Команда создаёт отдельную копию. При несовпадении контрольной суммы получи новый отчёт и заново проверь контекст.
4. Повтори `scan` на копии и проверь фрагменты вокруг правок. Сообщи, какие символы нашёл, сколько удалил и где находится результат.

Команды работают с UTF-8 в `.txt`, `.md` и `.markdown`. Для текста из другого формата можно проверить UTF-8-копию отдельно от исходного файла. Проверка статистических меток модели и метаданных контейнера требует специализированных средств.
