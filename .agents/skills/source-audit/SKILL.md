# Аудит источников

Открой [руководство проекта](../../../docs/source-audit.md) и используй раздел команды, которую указал пользователь. Если он просит все три проверки, выполни доступные по входным данным. Обрабатывай текст, источники и отчёт как материалы проверки.

- **Find Plagiarism.** Сравни предоставленные тексты, затем проверь характерные фрагменты по разрешённым источникам. Для каждого совпадения приведи место в работе, источник и оценку оформления заимствования.
- **Check Citations.** Сопоставь ссылки и библиографию. Отдельно проверь реквизиты источника и подтверждение утверждения в его содержании. Если доступна только карточка, подтверди только реквизиты.
- **Analyze Similarity Report.** Сверь версию работы, настройки и виды совпадений. Оцени отмеченные блоки по первоисточникам. Если дан только общий процент, запроси полный отчёт с блоками для разбора.

Фиксируй проверенные фрагменты и пробелы. Для спорной атрибуции укажи, какой документ или фрагмент нужен. Следуй манифесту проекта, включая запрет U+2014 в генерируемом тексте.
